# 3X-UI Desktop (Windows Client)

Нативный клиент для управления серверами [3x-ui](https://github.com/MHSanaei/3x-ui) на Windows 10 / Windows 11.

Приложение построено на базе высокопроизводительного системного движка **Microsoft Edge WebView2** (Chromium) и .NET Framework 4.8, не требует установки тяжелых платформ (Electron/Node.js) и запускается мгновенно.

---

## Возможности

1. **Менеджер серверов (мультисерверность):**
   - Быстрое переключение между серверами прямо из выпадающего списка на верхней панели или через меню системного трея.
   - Добавление, редактирование и удаление серверов.
   - Проверка связи с сервером прямо в окне добавления («Проверить связь»).
2. **Нативная поддержка самоподписанных SSL-сертификатов:**
   - Панели 3x-ui часто работают по IP или с самоподписанными сертификатами. Приложение автоматически разрешает такие подключения без пугающих браузерных предупреждений и блокировки WebSockets.
3. **Интеграция с Windows:**
   - **Системный трей:** Сворачивание в область уведомлений (возле часов), индикатор активного сервера, меню быстрого переключения серверов в трее.
   - **Тёмная тема (Dark Mode):** Системное оформление заголовка окна и панелей под тёмный стиль 3x-ui.
   - **Автозапуск с Windows:** Опция запуска в трей при старте системы.
   - **Сохранение сессий:** Сессии и куки авторизации сохраняются в постоянном профиле `%LOCALAPPDATA%\3xui-desktop\WebViewProfile`.
4. **Быстрая навигация и горячие клавиши:**
   - `F5` / `Ctrl+R` — Обновить страницу.
   - `F11` — Скрыть / показать верхнюю панель управления.
   - `F12` — Инструменты разработчика (DevTools).
   - `Ctrl +` / `Ctrl -` / `Ctrl 0` — Масштабирование интерфейса.
   - Быстрые кнопки перехода: *Дашборд*, *Inbounds*, *Настройки*.

## Запуск приложения

* Исполняемый файл: `3X-UI-Desktop.exe`
* Расположение: `C:\Users\user\.gemini\antigravity\scratch\3xui-desktop\3X-UI-Desktop.exe`

При первом запуске:
1. Нажмите кнопку **➕** на верхней панели или кнопку **📋** («Управление серверами»).
2. Введите название сервера (например, `Нидерланды VPS`) и полный URL (например, `https://194.87.12.34:2053/secretpath/`).
3. При необходимости нажмите кнопку **🔌 Проверить связь**.
4. Нажмите **Сохранить** — приложение автоматически откроет панель авторизации вашего сервера.

## Пересборка из исходников

Если вы хотите изменить исходный код или добавить новые функции:
1. Запустите файл `build.bat` двойным кликом (или выполните команду в консоли).
2. Скрипт использует стандартный системный компилятор `csc.exe` и соберет свежий `.exe` файл за 2 секунды.
